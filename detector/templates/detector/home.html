Behind the intelligence

Simple interface. Machine learning inside.

The application transforms text into numerical features and uses a trained classifier to predict whether it is sarcastic.

⌘

Word + Character Features

TF-IDF represents word patterns and character sequences so the model can learn from different text features.

◎

English + Hinglish

Trained using English headlines and a separately cleaned Hinglish dataset with human-provided labels.

↗

Fast Predictions

A saved Logistic Regression model processes your input directly through the Django application.
